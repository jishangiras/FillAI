# FillAI 0.1.2

FillAI is a privacy-first browser extension that fills forms from pasted or spoken natural language.

## Highlights

- In-page FillAI panel, no popup-first workflow.
- Review before fill.
- Local defaults and custom fields.
- Quiet confidence indicators.
- Chrome/Edge/Chromium and Firefox builds.
- Privacy-first local processing and local storage.
- New FillAI branding and browser icons.
- Optional donation link in settings.

## Assets

- `fillai-chrome.zip`
- `fillai-firefox.zip`

## Install

Chrome/Edge/Chromium:

1. Download and unzip `fillai-chrome.zip`.
2. Open `chrome://extensions`.
3. Enable Developer mode.
4. Load the unzipped folder.

Firefox:

1. Download and unzip `fillai-firefox.zip`.
2. Open `about:debugging#/runtime/this-firefox`.
3. Load `manifest.json` from the unzipped Firefox build.
